# 🎓 Eduzest Frontend

## 📌 Overview

Eduzest is a modern e-learning platform that provides an interactive and engaging experience for students, instructors, and admins.

The frontend is built using **React + TypeScript**, focusing on performance, scalability, and clean UI.

---

## ✨ Features

- 🔐 Authentication (OTP & Google Login)
- 📚 Browse Free & Paid Courses
- 💳 Secure Checkout (Stripe)
- 📺 Video Learning Experience
- 📝 Assessments & Exams
- 🏆 Leaderboard UI
- 💬 Real-time Course Chat
- 👨‍🏫 Instructor Dashboard
- 🛠️ Admin Panel

---

## 🛠️ Tech Stack

- React.js
- TypeScript
- Tailwind CSS
- Redux Toolkit / Context API
- Axios
- Socket.IO Client
